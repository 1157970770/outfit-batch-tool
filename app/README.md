# 换装批量生产器 · v0.9

**文件夹版程序，要整个文件夹一起拷，不能只拷 exe。**

```
换装批量生产器\
├── 换装批量生产器.exe   ← 双击这个
└── _internal\           ← 依赖文件，少了它 exe 起不来
```

分发时把 `换装批量生产器-v0.9-<日期>.zip` 整包发给别人，解压后双击 exe。

![界面](../docs/ui-preview.png)

---

## 第一次使用：输密码，然后就没了

**程序里没有任何需要你填的配置。**

1. 双击 exe → 弹「需要授权」→ 输入管理员分配的密码；
2. 激活成功后，服务端会把**百炼 Key、模板清单地址、COS 参数与上传凭证**一起下发，加密缓存在
   `%APPDATA%\RHOutfitTool\license.json`（Windows DPAPI，换机器拷走就解不开）；
3. 顶部四个状态灯应当全绿：`配置：已下发` / `模板清单：108 个` / `授权：至 2026-11-24` / `COS：开`；
4. 选一次输出目录 → 选服装图（无头模特图，只提供服装+上身效果）→ 填批次号 → 点「试跑 3 条」。

> 密码输错 3 次程序会退出；票过期或密码被停用，下次启动会被要求重新激活。
> 连不上授权服务时，只要上次成功核验在 7 天内，仍可离线运行。

## 输出长什么样

```
我的文档/换装输出/
└── 20261026A/            ← 你填的批次号（重名自动变 20261026A-2）
    ├── 001.mp4           ← 模板 001 的换装结果
    ├── 002.mp4
    ├── report.csv        ← 每条的状态/耗时/计费秒数/预估费用/大小，可直接给财务
    ├── batch.json        ← 本次用的提示词原文 + task_id / usage，可追溯
    └── log.txt           ← 运行日志
```

开了 COS 归档时，成品还会自动传到
`video-output-1463907213/prod/output/<日期>/<批次>/`；归档失败只记进 `archive_error`，**不影响出片**。
服装图会先传到 `prod/output/source/<日期>/` 并签 7 天 URL，供官方模型拉取；它不是成品。

## 界面上的几件事

| 位置 | 说明 |
| --- | --- |
| 顶部状态灯 | 配置 / 模板清单 / 授权 / COS 四项，缺哪项一眼能看出来 |
| 模板下拉 | 第 1–5 组（001–100 … 401–500），或「随机 100 条」。**清单不足 200 条时第 2–5 组会提示"模板不足"** |
| 并发 | 3（稳）/10/50/100；账号有并发上限，失败多就调回 3 |
| 提示词 | 可随意改，改完即用；原文会存进 `batch.json` |
| 暂停 | 暂停后不会提交新任务，正在跑的几条会跑完 |
| 已完成再点开始 | 同批次号会新建 `-2` 目录，不覆盖历史 |

**失败**：自动跳过并记在 `report.csv` 的「错误」列，整批不会中断。把失败编号记下来，单独再跑一次即可。

## 配置在哪（给运维看）

| 你想改的 | 改哪里 | 生效方式 |
| --- | --- | --- |
| 百炼 Key / 模型 / 模板清单 / COS 参数与凭证 / 公告 | 服务端 `server/config.json` → `license_deploy.py deploy` | 客户端**下次启动** |
| 谁能用、到哪天 | 密码管理器（`scripts\密码管理器.bat`） | 立即（每次启动都回表复查） |
| 程序连哪个授权服务 | `app/config.py:18` 的 `SERVICE_URL` | 改代码 → 重新打包 → 换 exe |

> 客户端没有 `配置.ini`、没有设置面板——**"改配置"永远是改服务端，不用重发软件**。
> 完整机制见 [../docs/license-integration.md](../docs/license-integration.md)。

## 开发者：重新打包

```powershell
.\scripts\build.ps1        # 或双击 scripts\build.bat
```

会自动：读 `app/main.py` 的 `APP_VERSION` → 关掉正在跑的旧实例 → PyInstaller（onedir）→ 自检 →
生成 `dist\换装批量生产器-v<版本>-<日期>.zip`。

> ⚠️ 打包会**删掉 dist 里其它版本的 zip**，要留旧包就先复制出去。
> 想换个输出目录试打：`.\scripts\build.ps1 -OutRoot build\release`。

**首次启动被 Windows 拦（「Windows 已保护你的电脑」）**：这是 SmartScreen 对**未签名**程序的信誉拦截，
不是报毒。点「更多信息 → 仍要运行」即可，或先双击包里的 `解除锁定并启动.bat`（清掉下载标记）。
要彻底不弹，必须买代码签名证书——证书到手后一条命令签名：

```powershell
$env:CODESIGN_THUMBPRINT = "<证书指纹>"
.\scripts\build.ps1 -Sign
```

原因、四种处理方式、多少钱，见 [../docs/distribution-signing.md](../docs/distribution-signing.md)。

**别用 `--onefile`**：单文件版每次启动都要把几百 MB 依赖解压到 `%TEMP%`，
在 TEMP 被管控（或被杀软实时扫描）的机器上会直接弹 `Could not create temporary directory!`
然后打不开。文件夹版不解压、启动更快，也更好排查。

- 无界面测试：`python3 tests/test_core.py`（核心引擎）、`python3 tests/test_ui.py`（界面集成）
- 模板上传与清单：`python3 tools/upload_templates.py` → `python3 tools/publish_manifest.py`

## 已知限制

| 限制 | 说明 |
| --- | --- |
| 密钥随授权下发到客户机 | 已评估并接受：子账号只能写成品区，不能读模板桶、不能列举、不能删除。边界与收口见 [../docs/adr-001-cos-client-credential.md](../docs/adr-001-cos-client-credential.md) |
| DPAPI 不是安全边界 | 它防的是"文件被拷到别的机器"，防不了"在本机被同一用户读取" |
| 必须整个文件夹一起拷 | 只拷 exe 会缺 `_internal`，起不来；已用 zip 分发 |
| 无界面自动更新 | 换模板/换 Key 只改服务端配置，无需发版；换程序要重新发 exe |
| 清单不足 100 条的整倍数时 | 后面的分组点不了（"模板不足"），先用「随机 100 条」 |
| 没有缩略图预览 | 按设计：大批量生产不需要辨认单个模板，只要分组编号 |
