## 2. 用法

第三个标签页「提示词库」有**缩小 / 展开**两种模式：

- **缩小**（默认）：每条只占一行——`序号 + 名字 + 字数`，右边「复制提示词」「展开」。六条一屏看完。
- **展开**：点「展开」露出全文，按钮变「收起」；正文可选中局部复制。
- 顶部「全部展开 / 全部收起」一次切换六条。
- **缩小状态也能直接复制**，不用先展开；复制后顶部提示「已复制：手串（272 字）」。
- 改完 JSON 点右上角**重新加载**，不用重启。

> 想填进「生产页」的提示词框：复制后自己粘贴。页面只做「看 + 复制」。

## 3. 数据在哪

| 运行方式 | 路径 |
| --- | --- |
| 源码运行 | `prompts/prompt-library.json` |
| 打包分发 | `exe 同目录\prompts\prompt-library.json`（`sys._MEIPASS` 里也放一份兜底） |
| 临时换一份 | 环境变量 `PROMPT_LIBRARY=D:\xxx\my.json` |

结构就三个字段，没有分类、没有标签：

```json
{
  "version": 1,
  "prompts": [
    { "id": "p01", "title": "服装定妆", "body": "负责定妆照提示词\n以@图片5 为唯一人物…" }
  ]
}
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | 否 | 缺省按位置补 `p01`… |
| `title` | 是 | 列表里显示的名字（就是你定的那六个） |
| `body` | 是 | 提示词全文，`\n` 换行 |

## 4. 原始记录与防改字

`prompts/raw/P-2026-10-27-01.md … -06.md` 是你六条提示词的**逐字存档**，`prompt-library.json` 由它生成。

`tests/test_prompts.py` 会逐条比对 **JSON 正文 == raw 原文**：哪天不小心改了一个字，测试直接红。要让提示词变化，改 raw 再重新生成，别只改 JSON。

---

## 5. 加一条 / 改名

- **改名**：改 JSON 里的 `title`，点重新加载。
- **加一条**：把新提示词发我 → 我存成 `prompts/raw/P-…-07.md` → 重新生成 JSON；或者你直接在 JSON 的 `prompts` 数组末尾加一个对象。
- 坏条目（缺名字/缺正文）会被跳过并在状态栏说明，不会整页白屏；JSON 本身写坏（少逗号）会报**行号**。

---

## 6. 明确不做的（按你的要求）

- 不做分类、不做标签、不做筛选——条数少时名字就是索引。
- 不做变量填值（你的提示词里没有需要每次替换的空位）。
- 不做评分、使用次数、版本历史。
- 页面只读，不提供编辑器。
