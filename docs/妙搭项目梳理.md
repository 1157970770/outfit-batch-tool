## 3. 分开之后各管什么

| 维度 | `miaoda-shell/`（过渡） | `miaoda/`（目标态） |
| --- | --- | --- |
| 上线要做什么 | 传 `dist/` 到妙搭静态站点 + 给后端一个 HTTPS 入口 + `web.json` 填 `cors_origins` | 妙搭跑 Node 容器 + 持久卷 + 注入 `PORT` |
| 页面范围 | 默认 `core` 5 模块，`all` 为 11 视图 | 11 视图全量 |
| 构建命令 | `node scripts/build.mjs <后端地址> [core|all]` → `dist/`；`node scripts/pack.mjs` → zip | `npm run build` → `apps/server/dist` + `apps/web/dist` |
| 文档 | `miaoda-shell/docs/部署.md` | `miaoda/docs/妙搭部署.md`、`parity-checklist.md` |
| 依赖 | `../miaoda/node_modules`（不重复安装） | 自己 `npm install` |
| 谁能改 | 前端页面改 `miaoda/apps/web`；套壳只碰自己的脚本/文档 | 同 |

> 共同点：**前端只有一份**（`miaoda/apps/web`），改页面会同时影响两条路线——这是刻意的，避免两边代码漂移；但**产物与部署互不覆盖**。

## 4. 已解决的冲突

1. **文档口径打架**（原：「主线=套壳，NestJS 降为回退」）→ 已改：`miaoda/README.md` 只讲全栈；`miaoda-shell/README.md` 与 `docs/部署.md` 只讲套壳，两侧互相指路，不说谁替代谁。
2. **产物混放**（原：`miaoda/dist-miaoda/` + miaoda 里的 `build:shell`）→ 已迁走：产物在 `miaoda-shell/dist`、`miaoda-shell/release`；`miaoda/scripts/build-shell.mjs` 只留一个转发（旧命令不静默失效），`package.json` 去掉 `build:shell`。
3. **套壳文档在错的地方**（`miaoda/docs/妙搭套壳部署.md`）→ 已移到 `miaoda-shell/docs/部署.md`，并去掉「方向调整」表述。

## 5. 仍需注意

1. **同一数据目录不能双跑**：Python 用 `msvcrt` 文件锁、Node 用 `server.lock.d` 目录锁，互不识别；灰度用 `web-data-miaoda/` 副本。
2. **并行提交**：另一进程也在这个仓库提交（`feature/canvas`），曾把我的文件卷进它的 commit。提交前 `git status`，只 `git add` 自己的路径。
3. **空壳目录** ⑥ 建议删除（需你点头）。
4. **旧 zip**：`dist/妙搭套壳-前端-20261111.zip` 是迁移前产物，已被 `miaoda-shell/release/妙搭套壳-前端-20261111-0951.zip` 取代，可删。

## 6. 下一步建议

- 套壳：拿到 HTTPS 入口后，`node scripts/build.mjs https://... core` → 上传 → 按 `docs/部署.md` §6 逐条验收。
- 全栈：补 COS 真连（需你同意产生对象）、双桶限流压测、视觉回归；随后在妙搭控制台确认容器/持久卷/端口三件事。
- 两条线都稳定后，用「套壳」维持日常访问、「全栈」做目标态切换，互不影响。
