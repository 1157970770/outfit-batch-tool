# 本机视频打标工具

这是一个**独立的本机小工具**：选择视频文件夹、创建标签、给视频打一个或多个标签，并导出 Excel 清单。它不上传视频、不访问 COS、不生成 manifest，也不调用 Wan 或生产网页。

## 启动

在主机双击仓库根目录的 `启动视频标签整理.bat`。如果主机还没装依赖，先执行：

```powershell
python3 -m pip install -r tools/requirements-tag-tool.txt
```

1. 点击“选择视频文件夹”，选择本机存放视频的文件夹。
2. 在列表中选择视频；右侧会自动开始**循环静音预览**，可用“上一个视频 / 下一个视频”连续浏览，键盘快捷键为 `A`（上一个）和 `D`（下一个）。若状态栏提示格式不支持，仍可继续按文件名打标。
3. 点击“新建标签”创建自己的标签值。默认提供：适合秋冬、适合春夏、近景、中远景、手串展示、A场景、B场景、C场景，也可以继续添加。
4. 单条视频在右侧勾选标签；标签以宫格排布，按 `W`/`S` 上下移动，按空格键勾选或取消当前标签。需要批量时，点“进入批量打标”，视频列表会显示“选择”复选框；勾选多条后点“批量打标签…”，可选择添加、移除或替换。也可以直接用 Ctrl/Shift 多选后批量打标签。
5. 点击“保存标签 Excel”或“另存为 Excel”，生成 `template-tags.xlsx`。

## Excel 内容

工作簿包含：

- **视频标签清单**：模板 ID、相对路径、文件名、时长、大小、文件指纹、标签和文件状态。
- **标签字典**：本项目创建的标签值。
- **项目**：项目 ID 和本机源视频文件夹位置，供稍后继续整理。

工具会保留已有视频 ID；新增视频追加编号，不因文件排序改变而重编号。源文件内容发生变化时会提示确认。Excel 可以保存未完成的草稿；之后重新打开可继续打标。

标签库保存在主机 `%APPDATA%\OutfitVideoTagger\tags.json`，与视频文件夹无关；可以先创建标签，再选择文件夹；新建的标签会跨文件夹、跨次启动保留。顶部“管理标签库…”可查看、新建、删除标签，也可用“合并到…”把旧标签替换成另一个标签（例如把“中远”合并到“中远景”）。删除/合并后即使直接关闭窗口也会保存，并同步更新当前项目。

默认的 8 个标签只在**第一次没有标签库文件**时创建；删除某个默认标签后，它不会因为重启再次出现。

## 键盘快捷键

- `A` / `D`：上一个 / 下一个视频
- `W` / `S`：标签列表内上移 / 下移（批量打标签弹窗内同样可用）
- 空格：勾选/取消当前标签（批量打标签弹窗内勾选标签）
- `Q`：清空视频选择和批量勾选
- `E`：打开批量打标签弹窗（不是切换批量模式）
- 回车：在批量模式下勾选/取消当前视频
- `Esc`：关闭批量打标签弹窗，不会退出批量模式

## 自动保存与继续工作

- 每次打标、批量打标、启动扫描、保存 Excel 时都会自动记录当前进度；另有 20 秒定时保存。
- 直接关闭工具不会丢失已打的标签。下次启动会直接读取缓存恢复上次文件夹和标签，**不会重新扫描全部视频**。
- 顶部“重新扫描”用于检查新增、删除或改动过的视频；只有需要时才扫描。
- 顶部“最近文件夹…”保留最近使用的 8 个文件夹，可快速切回，同样直接使用缓存。
- 缓存文件：`%APPDATA%\OutfitVideoTagger\state.json`。如果文件夹被移动或删除，工具会提示重新选择。

## 边界

- 清单只写本机文件的相对路径，不含 COS 地址、凭证或云端信息。
- 本工具不修改生产软件、云端清单或 COS 对象；Excel 是可独立保存、查看和交接的标签记录。
- 主机需要现有 Python/PySide6/openpyxl 环境；其他使用者不需要安装任何东西。若主机没有 `ffprobe`，工具仍可打标，但时长栏可能为空。
