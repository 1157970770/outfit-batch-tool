# 本机视频打标工具

这是一个**独立的本机小工具**：选择视频文件夹、创建标签、给视频打一个或多个标签，并导出 Excel 清单。它不上传视频、不访问 COS、不生成 manifest，也不调用 Wan 或生产网页。

> 自 v0.12.0 起，标签的**唯一真源**搬到网页服务的 `web-data/template_tags.json`，网页「标签」页与本工具共用这一份文件。Excel 降级为导入/导出通道，仍然可以独立保存与交接。

## 网页版标签页（所有登录用户可用）

导航栏「管理」与「RunningHub ↗」之间的**「标签」**页，就是本工具的能力搬到网页上的版本，非本机电脑的使用者也能用：

- 搜索 / 按状态（在用、已弃用、未打标）/ 按标签筛选，客户端分页（50/100/200）。
- 单条或批量改标签：覆盖、追加、移除三种方式。
- **弃用 / 恢复**：弃用的视频不再出现在小批量、大批量候选里；不删云端对象、不删本机文件，可随时恢复。
- **标签库维护**：新建标签、改分类、改名、合并、删除；**大类（如「景别」「场景」）也可新增、改名、删除**（删除前需先移走该类下的标签）。合并/删除会先显示「影响 N 条视频」，确认后立即生效，并记录操作人。
- 每次保存都会记审计（最近 500 条，可在快照里看到）；多人同时改同一条时，后保存的一方会收到「已被其他人更新」并自动刷新，不会静默覆盖。

同步策略刻意做成最省资源：**不轮询**。进页面时带 revision 拉一次（没变化只回几十字节），保存后用返回的受影响行局部更新；需要看别人的最新改动时点「刷新」。

### 配置与初始化

默认路径就是 `web-data/template_tags.json`，**不需要改配置**。只有想把真源放到别处时才在 `server/web.json` 写 `"tag_store": "路径"`，或用环境变量 `OUTFIT_TAG_STORE` 覆盖。

```bash
# 首次：把现有标签 xlsx 导入真源（先干跑对账）
python run_web.py --import-tags --dry-run
python run_web.py --import-tags
# 之后重启网页服务；进「标签」页核对条数与「可生成」数
```

`--dry-run` 会对比导入前后的可生成条数与未打标条数，二者不一致时拒绝写入（确认无误可加 `--force`）。

### 上传新视频（所有登录用户）

标签页右上角「上传视频」：

- 支持 mp4 / mov / m4v，单个 ≤ **50MB**，可多选、可拖入，逐个上传并显示进度。
- **必须至少选一个标签**（整批共用），避免又产生「未打标」废素材。
- 流程：浏览器 → 服务端暂存 → `validate_video`（时长 1–15 秒、分辨率、帧率）→ 直传模板桶 `input/tpl/` → 登记清单 → 补本地索引 `web-data/manifest_overlay.json` → 重建候选集。
- 上传成功即可用于生产（状态「可生成」）；文件名与清单里已有条目重复时自动改成 `名字-2.mp4`，COS 对象名另带随机后缀，**不会覆盖**既有文件。
- 编号自动顺延（`project.next_id`），操作人和文件都会记入审计与自动版本。
- 上传失败时会回删刚传的对象，桶里不留孤儿文件。

### 版本历史（整库快照）

标签页右上角「版本历史」把**整份真源**存成版本：每条视频的编号、标签、弃用状态、标签定义一起快照，所以能完整回到某一版的视频库。

- **自动版本**：每次改标签、弃用/恢复、改标签库、桌面端同步、导入，都会自动存一版，只保留最近 **50** 份。
- **手动版本**：填个备注（如「上线前」）点「保存当前为版本」，长期保留（上限 50 份）。
- **回滚**：选任意一版点「回滚到此版本」，视频库与标签一起还原。回滚前服务端会**自动留一份「回滚前备份」**，所以回滚本身也能撤回；版本里没有的（后来新增的）视频会从清单消失，但仍保存在那份备份里。
- 存放位置：`web-data/tag_versions/*.json.gz`（压缩后单版约 50–80KB），同目录 `*.meta.json` 是列表用的元数据。这些文件不入 git。

### 回滚

把 `web-data/template_tags.json` 改名（例如加 `.disabled-<时间>`），重启服务即自动退回原来的 xlsx 模式；`template_tags.json.bak` 是每次写盘前的上一版。

## 启动

在主机双击 `启动打标器.vbs`（排错用 `启动器\启动视频标签整理.bat`）。如果主机还没装依赖，先执行：

```powershell
python3 -m pip install -r tools/requirements-tag-tool.txt
```

1. 点击“选择视频文件夹”，选择本机存放视频的文件夹。
2. 在列表中选择视频；右侧会自动开始**循环静音预览**，可用“上一个视频 / 下一个视频”连续浏览，键盘快捷键为 `A`（上一个）和 `D`（下一个）。若状态栏提示格式不支持，仍可继续按文件名打标。
3. 点击“新建标签”创建自己的标签值。默认提供：适合秋冬、适合春夏、近景、中远景、手串展示、A场景、B场景、C场景，也可以继续添加。
4. 右侧标签分为 **景别、适合季节、场景、姿势** 四个页签：例如近景/中远景在景别，适合秋冬/春夏在适合季节，手串展示/坐在椅子上/只有上半身在姿势，其余环境和地点标签在场景。按 `1`–`4` 切换分类；`W`/`S` 上下移动，空格勾选或取消。管理标签库可给标签设置分类；新建标签时也需选择分类。需要批量时，点“进入批量打标”，视频列表会显示“选择”复选框；勾选多条后点“批量打标签…”，可选择添加、移除或替换。
5. 点击“保存标签 Excel”或“另存为 Excel”，生成 `template-tags.xlsx`。

## Excel 内容

工作簿包含：

- **视频标签清单**：模板 ID、相对路径、文件名、时长、大小、文件指纹、标签和文件状态。
- **标签字典**：标签值及其分类。
- **项目**：项目 ID 和本机源视频文件夹位置，供稍后继续整理。

工具会保留已有视频 ID；新增视频追加编号，不因文件排序改变而重编号。源文件内容发生变化时会提示确认。Excel 可以保存未完成的草稿；之后重新打开可继续打标。

标签库保存在主机 `%APPDATA%\OutfitVideoTagger\tags.json`，与视频文件夹无关；可以先创建标签，再选择文件夹；新建的标签会跨文件夹、跨次启动保留。顶部“管理标签库…”可查看、新建、删除标签并设置分类，也可用“合并到…”把旧标签替换成另一个标签（例如把“中远”合并到“中远景”）。删除/合并后即使直接关闭窗口也会保存，并同步更新当前项目。

默认的 8 个标签只在**第一次没有标签库文件**时创建；删除某个默认标签后，它不会因为重启再次出现。

## 键盘快捷键

- `A` / `D`：上一个 / 下一个视频
- `1`–`4`：切换“景别 / 适合季节 / 场景 / 姿势”分类页
- `W` / `S`：当前分类内上移 / 下移（批量打标签弹窗内同样可用）
- 空格：勾选/取消当前标签（批量打标签弹窗内勾选标签）
- `Q`：清空视频选择和批量勾选
- `E`：打开批量打标签弹窗（不是切换批量模式）
- 回车：批量模式主界面勾选/取消当前视频；在批量打标签弹窗内回车等于“确定”
- `Esc`：关闭批量打标签弹窗，不会退出批量模式

## 自动保存与继续工作

- 每次打标、批量打标、启动扫描、保存 Excel 时都会自动记录当前进度；另有 20 秒定时保存。
- 直接关闭工具不会丢失已打的标签。下次启动会直接读取缓存恢复上次文件夹和标签，**不会重新扫描全部视频**。
- 顶部“重新扫描”用于检查新增、删除或改动过的视频；只有需要时才扫描。
- 顶部“最近文件夹…”保留最近使用的 8 个文件夹，可快速切回，同样直接使用缓存。
- 缓存文件：`%APPDATA%\OutfitVideoTagger\state.json`。如果文件夹被移动或删除，工具会提示重新选择。

## 边界

- 清单只写本机文件的相对路径，不含 COS 地址、凭证或云端信息。
- 本工具不修改云端清单或 COS 对象；但会写 `web-data/template_tags.json`（与网页共用的标签真源）。Excel 仍是可独立保存、查看和交接的副本。
- 主机需要现有 Python/PySide6/openpyxl 环境；其他使用者不需要安装任何东西。若主机没有 `ffprobe`，工具仍可打标，但时长栏可能为空。

## 与网页端的分工

| 场景 | 用哪个 |
| --- | --- |
| 非本机使用者改标签、弃用、维护标签库 | 网页「标签」页 |
| 主机上批量浏览本机视频、按内容快速打标 | 本工具（预览与键盘流更快） |
| 新增视频到清单 | 仅主机：本工具扫描文件夹后保存；网页本期不提供新增 |
| 交接 / 备份标签记录 | 本工具「导出 Excel」，或 `python run_web.py --export-tags` |
