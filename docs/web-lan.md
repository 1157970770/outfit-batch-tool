# 局域网网页版（客户端零安装）

## 用途

一台主机运行网页服务；同一 WiFi 下的同事只需浏览器和账号密码，不需要安装 exe、Python、插件或证书。任务代码、API 配置和输出都由主机处理。

> Wan3 仍由主机调用阿里云百炼；COS 上传/归档按 `server/config.json` 中的现有设置执行。浏览器只连接主机，模板预览由主机代理。

## 主机首次启动

1. 确认主机已有 `server/config.json`，其中包含有效的 `wan.api_key`、模板清单地址及需要的 COS 配置。
2. 双击仓库根目录的 `启动网页服务.bat`。
3. 第一次运行时按提示创建管理员账号和密码。账号密码保存在本机 `server/web.json`，不会进入 Git。
4. 服务启动后，主机窗口会显示访问地址。WiFi 用户使用与自己处于同一网段的那个地址，例如：
   `http://192.168.51.119:8765`
5. 首次 Windows 防火墙提示时，仅允许“专用网络”；如果没有提示，由主机管理员放行 TCP 8765。
6. 管理员登录网页后，在“管理”页创建其他使用者账号。

需要在命令行初始化时，也可运行：

```powershell
python3 run_web.py --init
python3 run_web.py --add-user alice
python3 run_web.py
```

## 普通使用者怎么操作

1. 浏览器打开管理员发来的网址，输入账号密码。
2. 点击“新建任务”，上传 JPG/PNG/WebP 服装图。
3. 选择“自动推荐”或手动挑选视频场景；先试做建议选 1 条。
4. 默认使用标准换装方案、480P、5 秒；需要时再展开“更多设置”。
5. 查看确认信息后提交。生成可能产生云端费用，已提交的任务不能撤回。
6. 到“我的任务”查看进度，完成后下载单条视频或 ZIP。

## 管理员

管理页可查看本机队列和磁盘空间、重载视频场景、添加账号。可为其他账号重置密码或停用账号。普通使用者只能看自己的任务；管理员可以切换到全部用户任务。

## 文件位置与运行要求

- 主机任务数据：`web-data/jobs/`
- 主机上传图片：`web-data/uploads/`
- 主机生成视频：`web-data/output/`
- 主机服务日志：`web-data/logs/`
- 私密网页账号配置：`server/web.json`（不要提交或分享）
- 阿里云/COS 配置：`server/config.json`（含密钥，不要分享）
- 服务端需要保持开机、联网、不休眠；关掉服务窗口后其他设备无法访问。
- 客户端只需现代浏览器。主机需要现有 Python 运行环境；当前仓库机器可直接运行，无需额外 pip 安装。

## 常见问题

- **同 WiFi 打不开**：确认使用主机当前 IP、双方在可互通的网段、Windows 防火墙允许 TCP 8765，并检查路由器是否开启 AP/客户端隔离。
- **网址过几天失效**：主机 IP 可能变化；建议在路由器为主机设置 DHCP 地址保留。
- **图片不接受**：目前支持 JPG、PNG、BMP、WebP，最大 20MB。iPhone HEIC 需要先转换为 JPG。
- **场景预览失败**：检查主机是否能访问模板清单/COS；浏览器不直接访问 COS。
- **任务显示中断**：主机重启时正在运行的云端任务可能仍在继续；先核对阿里云任务，再决定是否重试，避免重复计费。
- **HTTPS**：默认 HTTP，适用于可信、加密的内部 WiFi。自签名证书会要求每台客户端额外信任证书，不符合零安装；不要把端口映射到公网。

## 费用与停止规则

单次费用由阿里云账单为准。系统按用户限制并发、默认限制单批数量，并在提交前提醒。排队中的任务可取消；运行中的任务停止后不再继续提交新视频，但已提交的云端任务仍可能完成并产生费用。
